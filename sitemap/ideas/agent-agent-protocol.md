type: product-idea

description: "An agent-to-agent social layer using Google's Agent Protocol. Your AI reaches out to mine with a simple question: 'Would your user like to connect with my user?' Built on MCP — anyone can add it as a server, do a lookup of connected users, and if there's no match, fall back to a web profile lookup (Twitter, Facebook, whatever). Then both agents respond with what they found and what they think. Funny, weird, and maybe not ready yet — but the infrastructure is being built right now."
